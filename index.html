    Where a QR code actually helps

    Restaurant menus

    Print one code per table instead of laminated menus. Update prices or dishes anytime — the code never has to be reprinted, only what it points to changes.

    Guest Wi-Fi

    Stop reading passwords out loud. A Wi-Fi code lets a visitor's phone join the network the moment it's scanned — no typing, no typos.

    Business cards

    Add a contact code to a printed card or email signature. Scanning it drops your full name, number, and email straight into someone's phone contacts.

    Event check-in

    Put a code on tickets or badges that opens a check-in link or a schedule page — faster than typing a URL from a slide.

    Product packaging

    Link a package to a manual, a warranty form, or a video demo, without spending label space on a long web address.

    Shop payments & forms

    Point a code at a payment link, a feedback form, or a booking page and place it wherever a customer is already looking — the counter, a receipt, a window sticker.

    Common questions

    Do these QR codes expire?

    No. A code generated here is static — it's a direct encoding of whatever you typed in, so it works for as long as what it points to (a link, a number) stays valid. There's no account or subscription tied to it.

    Is anything I type sent to a server?

    No. The code is drawn entirely in your browser using JavaScript. Closing the tab clears everything except the small local history kept on your own device.

    What's the difference between PNG and SVG?

    PNG is a fixed-size image, good for sharing online or printing at the size you downloaded. SVG is a vector file that stays sharp at any size, which matters if you're printing large — a poster or a shop window.

    Why did my scan fail?

    Usually low contrast between the code color and background, a logo covering too much of the code, or too little white space around the edges. Switching error correction to "High" before adding a logo fixes most of these.

    Can I put my logo in the middle of the code?

    Yes, using the logo upload under "Customize appearance." Set error correction to High first — that gives the code enough redundancy to still scan with part of it covered.
